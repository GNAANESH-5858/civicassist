# Languages (English, Tamil, Hindi)

## Interface

- `i18next` + `react-i18next`, bundled resources (no translation service at runtime). Setup is in `src/i18n.ts`.
- Two namespaces per language: `src/locales/<lang>/common.json` (pages, navigation) and `guidance.json` (engine messages: reasons, uncertainties, plan steps, questions, channels, safety).
- The selector in the header shows English / தமிழ் / हिन्दी. The choice is stored in `localStorage` (`civicassist.lang`) and sets `<html lang>`.
- Plurals use i18next suffixes (`day_one`, `day_other`).
- `src/locales/locales.test.ts` checks that Tamil and Hindi have exactly the English keys and the same `{{placeholders}}`, that no value is empty, and that every key used in the code exists.

### Adding or changing text

1. Add the key to `src/locales/en/*.json`.
2. Add the same key to `ta` and `hi` with the same placeholders.
3. Run `npx vitest run src/locales`.

## Engine

The engine is language-independent: `buildFrame` detects the script (Tamil, Devanagari, Latin; mixed text is fine), normalises digits and the Devanagari nukta, and matches multilingual keywords from `src/data/civic/complaint-types.json`. Routing, questions and plan steps are message keys with ids as parameters; `renderMessage` turns them into the selected language with names from the knowledge base.

Knowledge-base text (labels, channel instructions, authority explanations) carries `en`/`ta`/`hi` fields in the JSON files, chosen with `pick()`.

## Letters and PDFs

- `src/lib/letter/compose.ts` has native templates per language (for example Tamil `பெறுநர்: … இப்படிக்கு,`, Hindi `सेवा में, … भवदीय,`). Official designations stay in English as published.
- PDFs use Noto Sans fonts (OFL). Tamil and Devanagari are shaped with HarfBuzz (WASM) and drawn as vector outlines, so conjuncts and vowel signs render correctly. Latin text stays selectable.

## Scheme search

The 148 scheme records are English only. Tamil and Hindi questions are glossed to English topics (`src/lib/civic/schemeGloss.ts`) or rewritten in English by AI when available, and the page says so.

## Review status

Translations and the Tamil/Hindi evaluation examples were written carefully but **have not been reviewed by native-speaker experts**. Review them before relying on them in production.
